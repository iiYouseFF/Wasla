# Supplier / Wholesaler Dashboard

Next.js + TypeScript (web, responsive). Supplier brand / wholesaler distributor views share this app (role-scoped).

See `Docs/PRD.md` (S1-S7), `Docs/Screens_Repository.md` §2, `Docs/Wireframe_Specifications.md` §6-7.

```
supplier-dashboard/
  src/
    app/       # Next.js App Router (catalog, orders, promotions, analytics, settings)
    components/
    lib/api/   # typed client
```

MVP: catalog CRUD + bulk CSV, order management (confirm/pack/dispatch), payout history.
