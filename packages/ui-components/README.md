# @wasla/ui-components

Shared design system components (tokens from `Docs/Design_System.md`).

- Tokens: `tokens.json` / Tailwind config (color-primary etc., spacing, radius, elevation)
- Components: Button, Input (incl. OTP), Card, StatusBadge, BottomSheet/Modal, Toast, EmptyState, Skeleton, Stepper
- RTL & i18n from day one; 44×44 min tap target; WCAG AA contrast.

Consumed by retailer-mobile, agent-mobile, supplier-dashboard, admin-panel where feasible.
